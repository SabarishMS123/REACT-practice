## 📌 Repository Overview

This repository captures my daily progression in front-end development, focusing on component-driven design, state management, hooks, and clean code principles.

* **Hands-on Labs:** Focused isolation testing of single concepts (e.g., custom hooks, context workflows).
* **Mini-Projects:** Real-world implementations featuring routing, state stores, and external API integrations.
* **Architecture:** Structured patterns emphasizing reusable components, separation of concerns, and clean directory layouts.
